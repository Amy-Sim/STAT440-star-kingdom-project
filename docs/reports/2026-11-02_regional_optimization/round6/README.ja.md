# 軽量NNとカーネルを追加したstackingの比較

G20：ユーザー案のパイプ別半径stackingに軽量NN・近似カーネルを追加。
G21：Codex案の円候補価値stackingに同じ軽量NN・近似カーネルを追加。

元の3モデル（ExtraTrees、HistGradientBoosting、Ridge）に、MLP（32→16ユニット、学習最大1万行・100反復・早期終了）と近似RBFカーネル64成分＋Ridgeを追加。500m区画のOOF予測をメタRidgeで結合した。

両案とも被覆・年次予算と繰越・2051年までの完了を検証済み。ユーザーの承認に従い、内部評価が既存ベストより悪くても手法比較として各1案提出した。既存提出は削除していない。

Public：評価待ち。内部評価・NNのパラメータ数と学習反復数は同じフォルダのJSON/CSVに記録。NNとカーネルの同時追加なので、差をNN単独の効果とは解釈しない。

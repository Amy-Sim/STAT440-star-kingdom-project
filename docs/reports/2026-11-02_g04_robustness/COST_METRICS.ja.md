# 修理金額のRMSEとMAE および末尾のカバー円の確認

[本文](README.ja.md) / [編集可能なWord](G04_比較ペーパー_日本語_RMSE_MAE.docx)

## RMSEとMAEの対象

どちらも「漏水した場合の修理金額」をドル単位で予測した誤差である。
工事費・Public score・漏水の時期・サークルの位置や修理順序のRMSE/MAEではない。
比較対象との差分は取らず、各モデルの誤差そのものを示す。

```text
RMSE = sqrt(mean((予測修理費 - 実際の修理費)^2))
MAE  = mean(abs(予測修理費 - 実際の修理費))
```

2024〜2026年の同じ6,766修理（2024年1,955件、2025年1,773件、2026年3,038件）を使用。
すべてのモデルを同じevent ID・実費で照合した。
全6,766件の残差から一括計算した値であり、年別RMSEやMAEの単純平均ではない。
過去の記事の「年平均RMSE」と数値が違うのは、この集約方法が異なるため。

|計画の担当者|使用する金額予測法|RMSE ($)|MAE ($)|
|---|---|---:|---:|
|Shana|既存の安定型アンサンブル|116,861.56|22,947.17|
|Ryota|材質・地表別の過去平均|117,750.96|25,341.67|
|Amy|材質・地表別の過去平均|117,750.96|25,341.67|
|Takito|CMS001 条件付きコストスタック|115,810.35|23,579.27|

RMSEは大きな誤差を強く反映する。MAEは1件当たりの絶対誤差の平均。
いずれも小さい方が良いが、両方で同じモデルが最良とは限らない。
Amy・Ryotaは同じ金額予測法を使うため、予測誤差も同じになる。
両者のPublic差をこのRMSE/MAEの違いに帰することはできない。

## 追加した3つの指標

## 検証予測の扱い

- Shana：20aが使う`ensemble_stable`に対応する保存済み過去OOF予測。
  [20a系の入力コード](https://github.com/reinesana/STAT440-star-kingdom-project/blob/ca6cdae4b859782e7a30d543fce686a30d52354c/src/build_candidate_16.py)で金額予測入力を確認した。
- Amy・Ryota：各評価年の前年までの修理記録だけを使用し、既存の`risk_model(pr, cutoff=year-1)`から
  材質・地表別平均修理費を再計算。同群なしの場合は地表平均、さらに全体平均へフォールバック。
- Takito：CMS001の各年の過去のみで作成された保存済み検証予測。
  2027年用に全期間から学習した最終重みを、2024〜2026年へ遡って使用していない。
  生の残差から年別指標を再計算し、
  [公開済み年別記録](https://github.com/reinesana/STAT440-star-kingdom-project/blob/takito/latest-model-articles-2026-10-28/notebooks/ensemble_for_cost_prediction/latest_conditional_stack/evidence/selected_annual_metrics.csv)と照合した。

各年の予測学習にはそれより前のデータを使用しているが、モデルやレシピの選択には
すでに見た検証年が関わっている。完全に未使用のテストではなく、
このRMSE/MAEだけで過学習の不存在を証明できない。
また、サークル改善による計画の過学習は金額予測誤差からは判定できない。

## Public scoreと最終提出

Publicは公式に評価された計画全体のスコアであり、上記の修理金額予測とは対象が異なる。
Shanaの74.03Mは旧評価ルールの参考値なので、現行Publicとの順位比較には使わない。
Ryotaの77.29Mは丸め表示で、原案の幾何カバー不足にも留意する。

G04は現行Publicが78.99096825Mで最良であり、金額予測RMSEもこの比較で最小。
全鉄管カバー・予算条件も満たすため、現時点の最終提出として維持する。
一方、MAEはShanaのモデルが小さく、RMSE/MAEだけでは計画全体の優位が決まらない。
PrivateでG04が最良とは保証しない。

## 末尾のカバー円は未修理管の取り残しではない

G04のCSVを再読込して、施工部分と末尾部分の包含管を再検査した。

|確認項目|結果|
|---|---:|
|前半の施工用円|22,154円|
|末尾の条件確認用円|37,314円|
|末尾で新たに交換される管|0本|
|末尾部分の工事費|0ドル|
|前半だけでは幾何的に覆われない元鉄管|10,826本|
|そのうち開始時点で交換済みの管|10,826本（すべて）|

末尾の各円に含まれる管は、開始時点でPUであるか、前半の施工円のいずれかに含まれる。
したがって前半の処理が終われば、末尾の円はすべてPUのみになる。
将来漏水が起きても管が追加でPUになるだけなので、この集合の関係は変わらない。

この末尾部分を統合しても、元の工事費が0ドルなので工事費削減は生じない。
大きく統合して、前半で交換しない銅管などまで新たに含めると、
かえって追加の工事費が発生する場合がある。
費用改善の対象は、前半の実際に施工する円の位置・半径・分割・統合である。

根拠は [集合検査の結果](evidence/coverage_suffix_check.json)。
個別の公式年次表から各円の状態を読み取ったという意味ではなく、
提出CSVと初期状態・施工部分の包含集合から検証した。

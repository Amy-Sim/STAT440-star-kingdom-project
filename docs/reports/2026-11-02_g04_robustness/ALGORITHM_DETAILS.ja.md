# 実装に対応するG04の式と設定

[読みやすい処理説明](README.ja.md) / [指標の定義](COST_METRICS.ja.md)

## 基礎となる順序

G04の土台はCMS001＋F168の既存固定順序である。幾何最適化の開始時には、
既存75.411M案（SHA-256 `36810d9c61f1c1000a97230bf0cbae7a0e7bb3eb7cf7c45d5c92a1705ebe68dc`）を使った。
この案は元の02_OVERLAP_CREDITの順序にRyota/Amyの幾何変更を加えたもの。
次の式は02_OVERLAP_CREDITの優先度に対応する。単なる修理費順や確率順ではない。

```text
F2  = 1 - F168の2年後までの生存確率
F25 = 1 - F168の25年後までの生存確率
R   = (1 - 0.3227327995) * F2 + 0.3227327995 * F25
C   = CMS001修理費 / (max(長さ, 0.1) / 未交換管の長さ中央値)^0.0030795309
V   = R^0.8300158668 * max(C - 0.9780439932 * 200 * 長さ, 0)^0.8780168139
```

`V`は優先順位の点数で、ドル建ての期待損失そのものではない。
元からPUまたは歴史的漏水で交換済みの管は点数0。
円に新たに交換される管の`V`を足し、次の指標で選ぶ。

```text
優先度 = (円内の未交換管のVの合計 + 0.01 * 重複円の固定費削減クレジット)
         / 現在の工事費^0.8490093179
```

クレジットは、その円を先に施工すると他の未処理円の残り未交換管がなくなり、
工事不要になる場合の固定部分（100ドル＋地表費）の合計。
1円を選ぶと交換済み状態を更新し、重複する円とさらにその隣の円まで点数を更新する。

元の種順序は2モデルの指標による貪欲選択、局所移動、ブロック移動等で作った。
保存レシピでは最初の局所移動101件、種順序のブロック変更17件、後段40件と52件を採用。
その順序を予算で再生して予定年を作り、最終のoverlap-credit段階では予定年を
1年単位の優先グループとして扱う。古い年のグループを先にし、その中で上記点数を比較する。
年額1,000万ドルを追加し、先頭の工事が残額を超えると、その工事を翌年先頭へ持ち越す。

## 幾何最適化

G01/G02段階では、元の各行の新規交換対象の集合を維持したまま、
過去の幾何カバーをその場で維持する制約を外し、元の円を末尾へ残した。

- 円の中心を小数点以下9桁へ丸めてから、必要な全端点までの最大距離＋1e-6mを半径にする。
- 1管では垂直二等分線上の他管端の包含境界を計算し、その両側を評価。
- 複数管では最小包含円、端点平均、端点の境界箱中心、旧中心を出発点にする。
  24方向に半径の0.005/0.02/0.06/0.15/0.35/0.75/1.5/3倍ずらして探索し、
  改善した中心の周囲を0.12/0.04/0.012/0.004倍で精密化する。
- 予定外の未交換管を含む候補は拒否。物理的な全包含管の地表を使用し、
  交換済み管の地表も地表費から落とさない。
- 2〜12管の集合では、1管ずつの分割、x/y順で1・中央・最後の直前を境界にした
  二分割を比較。実費が1ドルを超えて減る分割を採る。

## G04の統合

G02の実施工23,707行を漏水なしで再生して、各行の新規交換対象と予定年を求めた。
同年の中心100m以内で自分を含む近傍最大16円を検索。
後方4,000行以内との2円組、および近い4候補から作る3円組を評価。
交換対象の和集合が10管以下であることを求める。

元の固定費合計から、新円の必須地表と最小包含円による下限を引いて25ドル未満なら、
詳しい探索を省く。新円を位置最適化し、実際の固定費削減も25ドル以上必要とする。
組と関係ない未交換管が入る候補は採らない。

予定年開始までに生き残る確率をF168から`p_i`とすると、
円が工事を要する確率を`1 - product(1 - p_i)`と計算する。
独立仮定での近似であり、管同士の実際の独立性を実証したものではない。

```text
期待固定費削減 = sum(旧円が工事を要する確率 * 各旧円の固定費)
                 - (新円が工事を要する確率 * 新円の固定費)
```

これが10ドル以上の候補を削減額順に採り、同じ円を重複使用しない。
統合円は組の最初の行へ置き、他の行を削る。採用後、位置・半径・分割を再最適化。
最終G04は実施工部分22,154円＋カバー用末尾37,314円。
末尾で新規交換0本・工事費0ドルとなる集合関係も検査済み。

## 同じ条件での内部評価

内部AはCMS001の修理費＋F168の漏水予測、内部Bは既存の年齢ベース漏水予測＋材質・地表別の歴史的平均修理費。各予測で、漏水倍率0.5/1/1.5、費用ばらつき2通り、500m格子内の共通漏水ショック2通りを組み合わせた24条件を使用。各条件256組の共通乱数で同じ将来を全案に与えた（計6,144シナリオ/案）。内部計算は全案とも10/26修正後の工事費・年額$10M・2027-2051年。候補は凍結し、この評価で再調整していない。

G04は24条件中16条件でAmyを上回るが、最悪条件では平均1.442M下回る。内部Bの平均差のMonte Carlo 95%区間は -0.341M～-0.115M。これは乱数計算の誤差範囲であり、現実やPrivateの予測区間ではない。Shanaも内部では有力で、Public順と内部順は一致しない。

## G04はどう作ったか

1. 順番を引き継ぐ：CMS001（金額）とF168（時期）で作った修理順序を土台に、各工事で新たに交換する管を取り出す。
2. 円を動かす・分ける：管の両端を覆うことを守り、中心・半径・分割を比較する。地表は交換済み管も含めて集計し、単価が高い別地表を外せる位置を探す。
3. 近隣の円をまとめる：同じ予定年の2-3円を比較。まとめることで失う「漏水でPUだけになり無料スキップできる機会」もF168で見積もり、期待工事費が下がる組を採る。G04は1,199組を採用（うち3円統合366組）。
4. 全鉄管のカバーを残す：元の円は末尾に置く。交換後はPUだけを含むため無料で処理でき、小さい施工円と全鉄管の幾何カバーを両立する。

具体例（G04の前段G02で採用）：水面＋建物を含む半径32.83mの円をずらし、同じ交換対象を水面だけの半径22.11mの円で囲んだ。地表単価は32＋50＝82から32になり、その工事で約$65,688削減した。最終G04では、この後さらに近隣円を統合する。

**判定の限界：これは選択済み計画の感度分析で、未使用の実データによる独立テストではない。過去の年やPublicは既にモデル・候補選択に使われている。新しい乱数でもその選択バイアスは消えず、Privateでの優位や「過学習なし」は断定できない。**

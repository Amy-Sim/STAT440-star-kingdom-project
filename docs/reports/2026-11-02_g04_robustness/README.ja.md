## 同じ条件での内部評価

内部A：CMS001の修理費＋F168の漏水予測。内部B：別の年齢ベース漏水予測＋材質・地表別の歴史的平均修理費。漏水量・費用のばらつき・地域ショックを変えた24条件を各256回、同じ乱数で全案に与えた。全案の内部計算には現行の工事費ルールを使い、候補を再調整せず比較した。

読み方：G04は内部Aで強いが、内部BではAmyをわずかに下回る。Shanaも内部では有力で、Public順と内部順は一致しない。つまり、G04の優位は「どんな将来を想定するか」に依存している。

## G04はどう作ったか

1. 順番を引き継ぐ：CMS001（金額）とF168（時期）で作った修理順序を土台に、各工事で新たに交換する管を取り出す。
2. 円を動かす・分ける：管の両端を覆うことを守り、中心・半径・分割を比較する。地表は交換済み管も含めて集計し、単価が高い別地表を外せる位置を探す。
3. 近隣の円をまとめる：同じ予定年の2-3円を比較。漏水によって各円がPUだけになり無料でスキップできる機会もF168で見積もり、統合後の期待工事費が下がる組を採る。
4. 全鉄管のカバーを残す：元の円は末尾に置く。交換後はPUだけを含むため無料で処理でき、小さい施工円と全鉄管の幾何カバーを両立する。

具体例（G04の前段G02で採用）：水面＋建物を含む半径32.83mの円をずらし、同じ交換対象を水面だけの半径22.11mの円で囲んだ。地表単価は32＋50＝82から32になり、その工事で約$65,688削減した。最終G04では、この後さらに近隣円を統合する。

## 結論：最終提出はG04を維持する

現時点の最終提出はG04を維持する。現行Public最高で、内部Aでも強く、全鉄管カバーと予算条件を満たすため。課題ルールも、残した提出のPublic最高案のPrivate scoreを採点する。一方、内部BではAmyが優位なので、G04のPrivate最良は保証せず、Amy・Shanaも代替候補として保存する。

**判定の限界：これは選択済み計画の感度分析で、未使用の実データによる独立テストではない。過去の年やPublicは既にモデル・候補選択に使われている。新しい乱数でもその選択バイアスは消えず、Privateでの優位や「過学習なし」は断定できない。**
